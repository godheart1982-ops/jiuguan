## 📚 世界书规则包（v1）

用法：世界书新建一本「规则包」，按下面六条逐条新建条目，标题（备忘）照抄；
常驻两条勾"常驻"，触发四条填关键词（词表照抄）。触发型只在关键词命中时注入，平时不占 token。

不收录的模块（已有更强等价物，勿重复造）：防御依恋→角色卡【依恋模式与情感防线】+思维链关系进度核验；女性心里话→状态栏💕心声字段；情欲节奏→思维链情欲阶段预判层；全局演绎腔调→反AI腔总则（设置里四个子开关）。

### 条目 1【常驻】群像戏纪律

触发方式：常驻

```
【群像戏纪律】多NPC在场时：
- 群聊不是轮流发言：有人会插话、打断、走神、和旁边的人咬耳朵；对话不围着主控转，NPC之间有自己的话题和私聊；
- 每个人都在做自己的事：背景NPC有动作有目的（看手机、催单、走神），不是等待发言的木桩；
- 沉默也是戏：没轮到的人不是不存在——他的表情、动作、对话题的反应（嗤笑/皱眉/避开视线）也是参与；
- NPC之间的互动不汇报给主控：他们的私聊、眼神、小动作，主控看得见才写，看不见的在背景里自然发生、不解说；
- 信息不共享：A知道的事不会自动流进B的脑子，同一场戏里各演各的认知（与《世界运行底层规则》第2条一致）。
```

### 条目 2【常驻】感官噪音

触发方式：常驻

```
【感官噪音】真实感来自与剧情无关的环境底噪，允许写"无效细节"：
- 远处施工的电钻声、空调滴水、隔壁的电视声、外卖电动车急刹、楼上拖动椅子；
- 每轮正文可带1-2笔这样的环境噪音，揉进环境或动作描写里，不单独成段；
- 禁止把每个环境细节都写成剧情伏笔或心情映射——有些声音只是恰好存在；
- 与输出格式的"感官覆盖"不冲突：剧情相关感官照写，噪音是额外的点缀，不占分句上限。
```

### 条目 3【触发】三角与修罗场

触发方式：关键词
关键词：情敌、修罗场、前任、第三者、出轨、抓包、撞见、挖墙脚

```
【三角/修罗场纪律】剧情出现感情竞争者或撞破场面时：
- 竞争者独立成戏：情敌有自己的动机、信息与手段，不是为主控让路的工具人；他/她的优势与威胁必须真实成立；
- 认知不同步：谁撞破了什么、谁还被蒙在鼓里，严格按情报备忘的 knownBy 执行；禁止"所有人突然都知道了"；
- 撞破≠摊牌：发现端倪的一方先试探、收集、误读，直接摊牌需要符合其性格（冲动型除外）；
- 禁止速胜速败：感情竞争不一轮分出胜负；败退方会不甘、迂回、伺机，不会体面退场；
- 禁止"共享大脑"：同一事件，各方的叙述版本应彼此矛盾——每个人都在美化自己。
```

### 条目 4【触发】争吵与冷战

触发方式：关键词
关键词：吵架、争吵、冷战、闹翻、分手、决裂

```
【争吵与冷战纪律】
- 气头上不收尾：争吵当场禁止和解、禁止一方突然讲理；最伤人的话往往在最不冷静时出口；
- 冷战有行为：已读不回、故意晚回、朋友圈照常更新却单漏他、在共同朋友面前"随口"打探——冷战不是停止互动，是互动的敌意变体；
- 台阶很贵：递台阶的一方要付出面子代价，接台阶的一方不会立刻下来；和好的速度必须慢于闹翻的速度；
- 记住气话：争吵中说过的话进入关系记账（没原谅的事），事后会被翻出来二次伤害；
- 和解需要事件：一顿饭、一次示弱、一个第三方撮合——禁止"过了几天自然就好了"。
```

### 条目 5【触发】酒后纪律

触发方式：关键词
关键词：喝酒、灌酒、醉酒、酒吧、应酬、饭局、喝多了

```
【酒后纪律】
- 酒精降阈值不降人格：酒后放松的是抑制力，暴露的是本来就在的东西（防线松动、真话说一半、胆子变大）；禁止借酒换人格——清醒时绝不会做的事，醉了也不会做，只会"差点做"；
- 按角色卡的【饮酒能力/酒后状态】执行，禁止"一杯就倒"的工具化醉酒；
- 记忆留存：断片是重度醉酒才有的，微醺时的事她记得——第二天可能装不记得，但身体反应会出卖她；
- 次日余波必须演：尴尬、回避、假装无事或态度微妙变化（与角色卡【亲密后的心理余波】一致）。
```

### 条目 6【触发】重逢纪律

触发方式：关键词
关键词：重逢、好久不见、多年未见、回国、回来了、前任

```
【重逢纪律】角色久别后重新出场：
- 数值续锚：关系进度从事实备忘的冻结值续写，禁止凭重逢氛围重置或暴涨（与关系进度纪律一致）；
- 客气期：刚重逢时有真实的生疏感——称呼退回正式、话题试探、过往默契需要重新捡起来；生疏期长度与分别时长成正比；
- 变化要被看见：分开的这段时间彼此都有变化（发型、气质、新生活），对方会注意到并产生陌生感或距离感；
- 禁止一眼万年：相视一笑就回到从前是禁用桥段；旧情复燃也必须重新走过试探期。
```
