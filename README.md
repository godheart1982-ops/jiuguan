# 酒馆 - AI 角色扮演客户端

轻量级 AI 角色扮演客户端：角色卡、多会话、记忆与世界书、插图与联网检索，连接 OpenAI / Anthropic / DeepSeek 等主流 API。  
支持 **Windows 桌面（Electron）**、**Android（Capacitor）**，另可构建纯网页资源。

当前 Android 版本：**2.1.148**（`versionCode` **202**）

---

## 功能特性

### 角色与会话

- **角色卡管理**：创建 / 编辑 / 删除；本地头像、主控信息、分组；分组折叠状态持久化
- **卡内模块**：背景设定 + 可增删的角色模块（每个角色一块设定文本，主角为第一块），按"背景设定→各角色模块"顺序全量常驻注入；老卡的角色描述自动并入第一块角色模块
- **提示词库**（侧边栏 📚）：内置状态栏输出格式/思维链/荒野求生三份模板，可编辑/导出/恢复默认，支持自定义模板（可选类型）；输出格式与思维链在卡编辑页**按卡选择加载**（下拉按类型筛选：输出格式下拉只出输出格式模板、思维链下拉只出思维链模板；卡级文本仍可覆盖，选"无"即不注入）
- **多对话**：每个角色可拥有多条独立会话
- **世界书（类 SillyTavern）**：常驻 / 关键词命中注入；角色卡专属条目 + 侧边栏「世界书库」绑定；扫描深度、递归、大小写；可开「扫描时忽略状态栏」（默认开，剥离 AI 回复的代码块与标题行再匹配，人名只靠正文触发）；不写历史、不进记忆。人物条目建议勾「不可被递归激活」：只在本人被近期聊天提及时加载，避免角色关系网被递归整片勾起
- **输出 / 思考格式**：角色卡内可配输出模块与思考格式等
- **每轮人设校准**：本轮输入末尾强制附带校准指令，生成前重核出场 NPC 的核心人格、关系名分与占有欲、性观念与亲密边界、对主控认知；防止近期回复反向覆盖角色卡，元指令轮不注入、不写入聊天历史
- **行动选项防串线**：API 历史仅保留最近一轮完整菜单用于格式示范与数字映射，较早菜单剥离；本轮输入标明实际所选项，未选项不得倒填为已发生事实；本地聊天记录保持原样

### API 与连接

- **主 API**
  - OpenAI 兼容 `/v1/chat/completions`
  - Anthropic 原生 `/v1/messages`（含 prompt caching）
  - DeepSeek 思考模式、火山方舟前缀续写等兼容路径
- **副 API（记忆索引与召回）**：可单独填 Base URL / Key / 模型，用于后台生成轮次索引与增量状态补丁、发送前筛选相关历史原文、补全缺失模块；留空则回退主 API
- **搜索 API（联网）**：与对话 API 独立（如 AnySearch）；聊天页 🔍 **仅用输入框原文**作查询，不上传角色卡与历史；结果拼进本轮发送，默认不进记忆
- **API 配置方案**：主/副 API 可保存多套方案快速切换（方案命名用应用内输入框，兼容 Electron 无 `prompt`）
- **API 测速 / 跑分**（「API 设置 → 高级」，主/副 API 均可测）：快速 1 次流式 / 完整 = 预热 1 轮 + 正式 N 轮；首 Token P50、总延迟 P95、输出 / 总体 Token/s、请求/分钟、格式遵循（简化状态栏机械校验）、DeepSeek 余额；记录持久化、可删除对比
- **Token 用量统计**：按角色 / 模型 / 日期统计输入、输出、缓存读等

### 记忆系统

- **当前状态账本**：常驻记录当前场景、人物外貌身材、成年性癖、外在/实际内在气质、关系/阶段/三轴/情绪/目标、关系约定与亲密边界、未完成约定、进行中事件及 NPC 个人计划；性癖仅指稳定而特别的 XP，普通体位/力度/节奏/地点偏好、一次尝试或主控单方面喜好均不收录；重要人物首次入库优先采用角色卡，缺失设定结合人设生成后固定，一次性路人不建立完整状态；`memory.profiles` 单独保存固定档案，重建状态时锁定复用、不重抽，动态外貌只按明确事件变化
- **关系与秘密知情**：`intel+knownBy` 只收录白名单内的未公开关系/身份、孕病伤、重大工作学业与财务变化、犯罪报复危险及明确保密计划，且须存在未知情者、提前知情会改变行为并有正文依据；同一事项合并更新全量知情人，公开后移除限制，日常琐事不入库
- **不在场重要 NPC**：输出格式在「其他在场 NPC」后常驻显示最多 3 人的最近场外状态，跨时段至少推进一条、同时段照抄，入场离场或用户明确新信息立即更新；人物账本同步 `presence` 与最近场外状态，入场后仅作衔接，显示被挤出不删除记忆；场外旁白不等于主控知情，电话视频不与在场模块重复
- **原文永久档案**：聊天消息是每轮详细原文的唯一存储，不在记忆里重复复制；索引按永久 `turnId` 引用当前选定稿，附内容版本与精简 `stateAfter` 快照；快照省略可由固定档案恢复的性癖/内外气质，分支与重发时自动回填；生成长期摘要也不会删除原索引或原文
- **每轮索引卡**：副 API 在回复完成后后台整理已退出最近窗口的上一轮，只携带本轮相关人物状态，角色卡仅在首次或档案缺失时附加；生成标题、摘要、人物、关键词、语义别名与话题及增量状态补丁；`sceneTime` 必须从状态栏提取完整剧情日期时间，禁止使用现实发送时间，编辑器可手改或从原文本地批量补齐；索引失败不丢原文，可重试；失败回复与当前中止稿不入库
- **固定分组长期记忆**：每 10 张连续索引由副 API 一级压缩为一条长期记忆，保存来源轮次、`turnId`、内容版本与剧情时间；上一条长期摘要仅供衔接，不做多条长期记忆的二次压缩；最近 10 条常驻，约覆盖 100 轮，中期历史不再完全依赖召回
- **发送前分级召回**：副 API 根据本轮输入、实际行动选项、当前状态和最近对话检查远史索引卡，在同一次粗筛中先把模糊指代改写成明确检索意图，相对日期按当前剧情时间换算并只用 `sceneTime` 消歧；普通明确或单一明确旧事候选一次完成，多候选旧事/长线回顾、指代不清或候选相似时才复选；粗筛与复选都只读取索引卡，不附候选详细原文；按 high/medium/low 分级，普通旧事最多 6 条、特定旧事 8 条、长线回顾 16 条；远史默认只给摘要，明确询问原话/具体互动或摘要冲突时才给最近 2 轮 high 的详细原文，low 直接丢弃；纯人名/地点/关系等宽泛重合不能单独构成召回理由，同一事件线选起点/转折/结果而非全选
- **大量索引分批并行**：单次最多 200 张卡，超过后多批副 API 并行粗筛，再对候选汇总复选；单批失败可由其他批次兜底，召回失败不阻塞聊天；不再使用延迟一轮的「记忆调取 #N」
- **连续剧情脉络**：主 API 常驻当前尚未压入长期记忆的短期组全部索引（不再固定最近 5 张），附轮次、标题、摘要与剧情时间；失效或尚未生成的长期组暂时用原索引兜底，排除动态原文窗口与本轮召回重复项，历史场景、衣着、情绪与数值仍以当前状态和最新原文为准
- **动态原文窗口**：发送时由本地检查总结进度，最近 1 轮始终携带完整原文，连续尚未整理或索引版本失效的新轮次也全部携带，直到最近一张有效索引；不卷入新记忆系统启用前的旧聊天，后台仍保持延迟 1 轮整理，失败时提示并可重试；历史原文只代表过去，不覆盖当前状态
- **刷新 / 编辑 / 分支**：最新稿刷新或换稿不重复入库；旧轮编辑会使相关索引与长期摘要失效并标记状态待重建，旧摘要停止常驻；编辑重发按重发点截断档案并恢复之前快照；从旧消息分支只保留来源完整的长期摘要并恢复该点的 `stateAfter`，不误用最新状态；冲突优先级为当前状态与最新原文、召回详细原文、召回索引摘要、长期背景摘要
- **记忆编辑器（全屏）**：主记忆页签为当前状态 / 对话索引 / 长期记忆 / 召回记录，支持手改、索引与长期摘要重建、来源查看、召回测试、待整理补做与按原文重建状态；索引每页 20 张、最新优先并支持页码跳转，详细原文仅在展开时读取；召回记录最多保留最近 20 条；Token 分别显示常驻记忆与全量索引库，不统计聊天详细原文、`stateAfter` 快照或召回记录，并在停止编辑 300ms 后防抖更新；保存采用三方合并：未手改部分接收后台新结果，用户明确修改或删除优先；免费生图记忆、外貌锚点、补充设定和剧情线页签保留
- **可选关闭记忆**：不生成索引、不更新状态、不召回，也不调用记忆副 API；仅按卡级设定轮数携带原文，已有档案保留，重新开启后可补整理
- **记忆修正通道**：主模型发现记忆矛盾时仍可在末尾上报「记忆修正：…」，后台整理时作为权威更正转成定点状态更新（可在「其他设置 → 生成行为」关闭）

> 向量记忆（语义检索预取）仅有设计稿（`docs/vector-memory-design.md`），**未实现**；当前采用“动态原文窗口 + 连续索引 + 一级长期摘要 + 副 API 远史召回”。

### 插图

侧边栏独立 **「插图设置」**（与「其他设置」分离，避免一页过长）。

- 后端：pollinations / 火山方舟 Seedream / 阿里百炼万相 / Google Gemini / xAI Grok Imagine / 手动模式等（pollinations 免费模式可选 NSFW 提示词开关，默认强制 SFW）
- 付费链路可由副 API 整理提示词；图片可存本地
- 人物模式：单人 / 双人（主控背影等，Grok / 手动）
- 镜头：景别 / 朝向 / 俯仰 / 画幅，可关交给模型
- 私密场景强制衣着：占位符由 App 机械替换模板库（含随机配色）
- **外貌身材锚点** + **免费生图记忆**（插图种子 + 英文外貌锚点，免费模式落盘时由 App 机械拼进 pollinations URL 锁脸，种子基准锁定不漂移）：同角色多轮出图更稳
- 点击灯箱放大、缩放拖拽；手动模式可复制提示词去外部 App 生成

### 聊天体验

- **流式输出**；Android 生成时前台保活
- **跟随式滚动**：流式生成中上翻阅读即暂停滚底、回到底部自动恢复；记忆总结 / 插图完成后的重渲染不再强制回底
- **空发送推演**：输入框留空点发送，按设定 / 记忆 / 状态栏自行推演，场景连续性优先（进行中的互动不中断，日程 / 约定仅作兜底）；指令可在「其他设置」自定义
- **作者注释**（聊天页工具面板 📝）：写给 AI 的常驻要求（如"保持她的毒舌"），按深度（0=请求末尾，N=后面留 N 条）与频率（每轮 / 每 N 轮 / 0=暂停）以 system 身份插入每次请求；不进聊天记录、不进记忆，禁止角色回应注释本身
- **长对话分页**加载；消息搜索与轮次跳转
- **对话分支**：消息右键「从这里分支」——该条及之前的消息与对应原文索引、状态快照、剧情线/锚点/作者注释深拷贝为新对话并跳转，原线保留
- 暗色酒馆风格；字体大小等 UI 设置
- 发送前预览（调试用，可开关）

### 数据备份与云同步

- **本地 JSON** 存储，隐私可控
- **整包加密备份**（AES-GCM + PBKDF2）
  - 导出 / 上传云前设置口令（明文输入便于核对，口令不存本机）
  - 导入 / 从云恢复时每次输入口令
  - 加密后含完整配置与 API Key；无口令无法阅读文件内容
  - 兼容旧版明文 / 脱敏备份
- **坚果云 / WebDAV 云备份**（「其他设置」）
  - 默认地址 `https://dav.jianguoyun.com/dav`；用户名=邮箱；密码=官网应用密码
  - **设备名称**区分多端；文件名：`backup-YYYYMMDD-HHmmss-设备名.json`
  - **单击**「从云恢复」：恢复本设备最新一份
  - **长按**「从云恢复」：列出云端目录**全部**备份（含其他设备），自选恢复
- Android 本地导出可走系统分享

| 层 | 技术 |

## 快速开始

### 环境

- Node.js（建议 LTS）
- 桌面：无需额外 Android 环境
- Android 打包：需本机 Android SDK；脚本会尝试探测常见 `JAVA_HOME` / `ANDROID_HOME`

```bash
npm install
```

### Windows 桌面

```bash
npm start                 # 开发运行（Electron，改 src 即可测）
npm run build:win         # 便携版 exe → dist/windows/
```

> 说明：`npm start` 只开桌面版；安卓需打 APK 或模拟器，不能用 `npm start` 直接看安卓壳。

### Android

```bash
# 一键：前端资源 → cap sync → Gradle 打 debug APK（默认自动 versionCode/versionName +1）
npm run build:android
```

分步：

```bash
npm run build:android:assets   # → dist/android-web/
npm run build:android:sync
npm run build:android:apk
```

产物：

```
android/app/build/outputs/apk/debug/app-debug.apk
```

跳过升版：`SKIP_VERSION_BUMP=1` 或见 `BUILD.md`。  
更细的打包说明见 **[BUILD.md](./BUILD.md)**。

### 网页资源

```bash
npm run build:web         # → dist/web/
```

## 使用说明（简要）

1. **API 设置**（侧边栏）：主 API / 副 API / 搜索 API；可保存多套方案。  
2. **插图设置**（侧边栏）：开关、服务商、Key、衣着库、compose、测试生图。  
3. **其他设置**（侧边栏）：字体、空窗指令、调试预览、**加密备份**、**坚果云 WebDAV**。  
4. **新建角色**：设定描述、主控、输出格式；可开世界书。  
5. 进入 **聊天**；可多会话；留空发送 = 空窗推演。  
6. **编辑记忆**：当前状态 / 对话索引 / 长期记忆 / 召回记录 / 种子 / 锚点。
7. 需要时用 🔍 联网；用「世界书库」管理公共条目。

### 坚果云备份（简要）

1. 坚果云官网 → 账户信息 → 安全选项 → **添加应用密码**。  
2. 其他设置填写：地址、邮箱、应用密码、**设备名称**（如「手机」）、云端目录。  
3. **上传到云**：输入备份口令 → 加密后上传。  
4. **从云恢复**：单击=本设备最新；长按=全部文件列表自选（可恢复其他设备备份）→ 输入口令解密。

## 数据存储位置

### 桌面端（Electron）

```
%APPDATA%/jiuguan/data/
├── config.json           # API / UI / 搜索 / webdav 等配置
├── characters/           # 角色卡 + 头像
├── chats/                # 会话与记忆等（.meta.json=列表索引，.ping=生成心跳，均为边车小文件）
├── worldbooks/           # 独立世界书库（若有）
└── …                     # 生成图等其它本地文件
```

（具体子目录以 `src/services/storage.js` 中 `PATHS` 为准。）

### Android

App 私有目录，经 Capacitor Filesystem 读写。换机请用 **加密备份导出** 或 **WebDAV 云恢复**。

## 开发说明

- 前端为浏览器 ES Module；改 `src/` 后：
  - 桌面：`npm start`
  - Android：`npm run build:android`（或 assets + sync + apk）
- 工程结构说明见 **[docs/engineering-structure.md](./docs/engineering-structure.md)**
- 关键纯函数有最小单测（`tests/*.test.mjs`，原生 `node --test`，无需额外依赖）：`npm test`
- ESLint 最小配置（`eslint.config.mjs`，只抓 bug 不管风格）：`npm run lint`
- 数据迁移集中在 `src/services/migrations.js`：config/chat 各一张幂等步骤表，加字段只在表尾加一步
